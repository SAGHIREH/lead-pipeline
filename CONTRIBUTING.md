# Contributing

We welcome contributions! Please follow these rules:

1. **Commits**: We use [Conventional Commits](https://www.conventionalcommits.org/). Example: `feat(intake): add HMAC validation`
2. **Architecture**: Any major architectural change must be documented in an ADR (Architecture Decision Record) inside `docs/adr/` before implementation.
3. **Testing**: Ensure all fixtures in `tests/` pass before submitting a Pull Request.
